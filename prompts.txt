You are implementing the POS Terminal feature for Kraft Market.

Context:
- NestJS backend with Socket.IO (@nestjs/websockets)
- Redis for cart state (TTL 4 hours per terminal)
- MongoDB for order persistence
- Next.js frontend with real-time UI

Backend — POS Gateway (WebSocket):
```
Namespace: /pos
Events to handle:
  Client → Server:
    'terminal:open'       { terminalId, staffId }   → load cart from Redis, emit 'cart:loaded'
    'cart:add'            { terminalId, productId, qty }  → HSET cart, check stock, emit 'cart:updated'
    'cart:remove'         { terminalId, productId }  → HDEL, emit 'cart:updated'
    'cart:clear'          { terminalId }             → DEL cart key, emit 'cart:cleared'
    'payment:initiate'    { terminalId, method }     → lock stock (Redis SETNX), emit 'payment:processing'
    'payment:confirm'     { terminalId }             → create Order (MongoDB), clear cart, emit 'payment:success'
    'payment:cancel'      { terminalId }             → release lock, emit 'payment:cancelled'

  Server → Client:
    'cart:loaded'         { items[], total, vat }
    'cart:updated'        { items[], total, vat }
    'payment:processing'  { orderId, amount, qrUrl? }
    'payment:success'     { orderId, receiptNumber }
    'payment:failed'      { reason }
    'stock:alert'         { productId, remaining }   → when stock < 5
```

Redis POS cart schema:
```
Key: pos:cart:{terminalId}   (Hash, TTL 4h)
Fields: {productId} → JSON string of { productId, name, price, qty, image }

Key: pos:lock:{orderId}      (String "1", TTL 30s)
Key: pos:terminal:{terminalId} → { staffId, openedAt, shiftTotal }
```

Stock reservation flow (race-condition safe):
```typescript
// Lua script for atomic stock check + decrement
const decrementStock = `
  local stock = tonumber(redis.call('GET', KEYS[1]))
  if stock == nil then return -1 end
  if stock < tonumber(ARGV[1]) then return 0 end
  return redis.call('DECRBY', KEYS[1], ARGV[1])
`;
```

Payment methods:
1. Cash: immediate confirm → create order
2. PromptPay: generate QR (Thai QR Prompt Pay spec), poll payment gateway every 3s, timeout 5min
3. Card: call card terminal API → await callback webhook

Frontend — POS Terminal page (app/admin/pos/page.tsx):
```
Layout: full-height, no scroll
├── POS Header: terminal info, shift total, quick actions
├── Left panel (flex: 1): product search/scan, category chips, product grid
└── Right panel (420px): current bill header, cart items, totals (subtotal/VAT/discount/total), payment buttons

Payment modal (not position:fixed — use faux-viewport div):
```


2. Rate limiting — ThrottlerModule:
```typescript
ThrottlerModule.forRoot([
  { name: 'short', ttl: 1000, limit: 10 },    // 10 req/sec
  { name: 'long',  ttl: 60000, limit: 100 },  // 100 req/min
])
// Stricter for auth endpoints
@Throttle({ short: { limit: 3, ttl: 60000 } })
@Post('login')
```

3. JWT Auth with Redis session blacklist:
```typescript
// On logout: add token to Redis blacklist
await redis.setex(`blacklist:${jti}`, jwtExpiry - Date.now() / 1000, '1');
// In JWT strategy: check blacklist before allowing request
const blacklisted = await redis.get(`blacklist:${payload.jti}`);
if (blacklisted) throw new UnauthorizedException();
```

4. Input validation — global ValidationPipe:
```typescript
app.useGlobalPipes(new ValidationPipe({
  whitelist: true,           // strip unknown fields
  forbidNonWhitelisted: true,
  transform: true,
  transformOptions: { enableImplicitConversion: true },
}));
```

5. MongoDB injection prevention:
```typescript
// Never use raw strings in queries
// ❌ Wrong: Model.find({ name: req.body.name })
// ✅ Right: always use DTOs + class-validator @IsString() @MaxLength()
```

6. CORS — strict origin:
